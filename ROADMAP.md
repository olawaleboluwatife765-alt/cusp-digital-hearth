# Cusp Development Roadmap

## Vision

Cusp is evolving from a high-fidelity prototype into a production-ready self-custodial Bitcoin and Stacks wallet.

Our roadmap prioritizes user experience, security, and trust before introducing live blockchain functionality.

---

# Current Status

**Stage:** Interactive Prototype

The current application focuses on validating:

- User experience
- Information architecture
- Visual design
- Onboarding flow
- Navigation
- Wallet interactions

All blockchain functionality is currently simulated.

---

# Phase 1 — Product & Prototype ✅

### Goals

- Premium onboarding experience
- Interactive wallet dashboard
- Explore ecosystem hub
- Pulse information center
- Connect dApps interface
- Security & recovery flows
- Responsive mobile-first design

**Status:** In Progress

---

# Phase 2 — Backend Foundation

### Objectives

- Google Authentication
- User account management
- Secure session handling
- Encrypted wallet metadata
- Backend infrastructure
- API architecture

**Goal:** Transition from a static prototype to a functional application backend.

---

# Phase 3 — Wallet Engine

### Objectives

- Wallet generation
- Wallet restoration
- Secure key management
- Recovery phrase support
- Address generation
- Local encrypted storage

**Goal:** Build the core wallet experience while preserving self-custody.

---

# Phase 4 — Blockchain Integration

### Objectives

- Bitcoin integration
- Stacks integration
- Transaction signing
- Transaction broadcasting
- Portfolio synchronization
- Network management

**Goal:** Replace simulated interactions with real blockchain functionality.

---

### Objectives

- Mainnet release

---

# Long-Term Vision

Future versions of Cusp may include:

- Hardware wallet support
- Passkey authentication
- Multi-device synchronization
- Advanced portfolio insights
- Multi-wallet management
- Cross-platform desktop applications
- Institutional wallet features
- Developer SDKs

These features will be evaluated based on community feedback and ecosystem needs.

---

# Guiding Principles

Every milestone follows the same priorities:

1. Security before convenience.
2. Simplicity before complexity.
3. Self-custody before custodial alternatives.
4. Trust through transparency.
5. Quality over speed.
